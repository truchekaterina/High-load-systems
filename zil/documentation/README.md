# Labs_hls

Базовые задачи курса по высоконагруженным системам.

## Публичный GitHub

Перед `git push` проверьте, что в коммит не попали **личные** пароли, токены и ключи. В репозитории настроены шаблоны `.gitignore` для `.env`, `application-local.properties`, `*.pem`, keystore и т.п. — храните реальные секреты только в таких **игнорируемых** файлах.

В модуле **`zil`** в `application.properties` и `docker-compose.yml` заданы **учебные** логин/пароль БД (`rental` / `rental_pass`) для локальной отладки; это не продакшен. Если вы когда‑либо использовали **тот же пароль** для важных сервисов — смените его там и не подставляйте в проект.
