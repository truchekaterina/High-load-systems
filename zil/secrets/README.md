# Локальные заметки (не коммитятся)

Сюда можно положить **только на своём ПК** текстовые файлы с паролями к учебному стенду (`zil/secrets/passwords.txt`, и т.д.).

Эта папка перечислена в корневом `.gitignore`, чтобы содержимое **не попало в git** при случайном `git add -A`.

**Важно:** стандартный OpenSSH для Windows не умеет читать пароль из файла и подставлять его в SSH автоматически. Чтобы **вообще не вводить** пароли при каждой сессии, используйте отдельный SSH-ключ **без passphrase** только для этого курса (`IdentityFile` в `~/.ssh/config`). Пароль в файле здесь может быть просто блокнотом на память или для других клиентов, не для авто-подключения OpenSSH.
